Can System 0 run Doom?
It decides every tic.

Doom runs at 35 tics a second. An LLM played it with the game paused, and shad0w learned its choices into a – table. Then six decision makers played the same games in real time: shad0w, two hosted LLMs, and three open System One decision models (Julia-1, Laya, Kev-4B) served by llama.cpp on the same laptop. While a lane's answer is on its way, its marine stands still. Every frame below is real ViZDoom (Freedoom assets), replayed move for move from the recordings.
