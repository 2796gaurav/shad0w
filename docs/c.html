C & other languages#

The C core is one file, reflex.c, plus a header, shad0w.h. It needs only libc and libm, and a decision takes about a microsecond.

1. Get the two files#

They ship inside the Python package:

D=$(python -c "import shad0w, os; print(os.path.dirname(shad0w.__file__))")/_native
cp $D/shad0w.h $D/reflex.c .

2. Decide#

#include <stdio.h>
#include <string.h>
#include "shad0w.h"

int main(void) {
  S0Reflex *m = s0_load("bundle/intent.s0");            /* NULL if missing or corrupt */
  if (!m) return 1;
  const char *text = "my card was stolen";
  float probs[S0_MAX_CLASSES], radius;
  int k = s0_decide(m, text, (int)strlen(text), probs, &radius);
  float threshold = 0.911f;                              /* from bundle/manifest.json */
  if (probs[k] >= threshold) printf("option %d, certified\n", k);   /* manifest options[k] */
  else printf("ask the LLM\n");
  s0_free(m);
}

3. Build#

cc -O2 app.c reflex.c -lm -o app

The answer is option k in manifest.json's options list (same order). It is certified when probs[k] >= threshold, also from manifest.json. A loaded table is read-only and can be shared across threads; give each thread its own probs buffer.

Other languages#

  • Go: cgo (// #include "shad0w.h").
  • Rust: bindgen or a 5-line extern "C" block.
  • Swift / Objective-C: add both files to the target.
  • Java / Kotlin: JNI or Panama.
  • Anything else: the HTTP server or the proxy.

Functions#

Function What it does
S0Reflex *s0_load(const char *path) load a .s0 table; NULL on any error (wrong version, truncated, unsorted keys)
int s0_decide(m, text, len, probs, &radius) index of the best option; writes every option's probability and the robustness radius
uint32_t s0_num_classes(m) number of options
double s0_bench(m, texts, lens, n, reps, per_call_ns) mean nanoseconds per decision
void s0_free(m) release
