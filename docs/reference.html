Reference#

Everything shad0w exposes, on one page. The settings and flags tables below are generated from the package source at build time, so they always match the released version.

shad0w.decision(...)#

shad0w.decision(name="decision", options=None, llm=None, *, folder=None, bundle=None, log=None,
                fallback=..., on_decision=None, trace=None, metrics=None, probabilities=False, config=None,
                **settings_and_llm_options) -> Shadow
Parameter Meaning
name What the decision is called. It names the folder (shad0w/<name>/), the field in the log, the question inside the bundle, the dashboard label and the Decisions-API question. Use one name per decision: decision("intent"), decision("urgent").
options The answers to choose from: a list, {name: description}, or {"type": "yesno", "instructions": "..."}. Optional once a table exists. Compared with the trained table to catch changes.
llm The teacher: "provider/model" (providers), shad0w.llm_teacher(...), or any fn(text) -> answer. Omit it to run without an LLM.
folder, bundle, log Where things live. Default shad0w/<name>/bundle and shad0w/<name>/log.jsonl.
fallback The answer when the table defers and there is no llm: a value, or fn(text) -> answer. Never logged as training data.
on_decision fn(decision, text) called after every decision.
trace A JSON Lines file that receives every decision.
metrics A shared shad0w.Metrics (several decisions, one dashboard).
probabilities Fill Decision.top on every call (a little slower).
config Path to a shad0w.toml.
settings Any setting from the table below, for example alpha=0.02, canary=0.1, max_mb=1.
LLM options base_url, api_key, client, complete, system, temperature, timeout, retries, headers, structured, max_tokens (see Connect your LLM).

shad0w.Shadow#

decision() returns a Shadow. Build one directly when you already have a teacher function and a bundle path:

sh = shad0w.Shadow("bundle/", teacher=ask_llm, question="intent", log="log.jsonl", **settings)
Method What it does
sh(text) / sh.decide(text) The table's answer when certified, else the teacher's (logged), else the fallback. Returns a Decision.
await sh.adecide(text) The same for async code. The table never leaves the event loop; sync teachers run in a worker thread.
sh.peek(text) The table's answer when it would be served, else None. Never calls the teacher.
sh.record(text, answer) Log an answer you got yourself (a person, your own LLM call).
sh.explain(text) What the table thinks: answer, confidence vs threshold, top options, and why, in plain words. Does not call the teacher.
sh.train(...) Compile and certify from the log, save, hot-swap. Returns the certificate plus accepted.
sh.stats() Counts, share answered, live spot-check bound, latency, flags, options_added, options_removed.
sh.reload() Pick up a bundle retrained elsewhere.
sh.flush() Wait for background spot checks (tests, shutdown).
sh.options_added, sh.options_removed Options changed since training (see Changing your options).

Decision#

Field Meaning
answer The option name (or True/False for yes/no questions).
source "table" (answered locally), "teacher" (your LLM answered and it was logged), or "fallback".
certified True when the answer is covered by the certificate.
confidence The table's confidence, or None when no table was consulted.
flag Why the table did not answer (see the flags below), or None.
latency_us Time for this call.
question, threshold The question's name and its certified confidence threshold.
top Options by probability, when probabilities=True.

Flags#

Flag Meaning
no_bundle no trained table yet: asked your model
low_confidence table not sure enough to stay inside the certified bound: asked your model
low_radius input could be flipped by a few edits (exposed mode): asked your model
drift traffic looks different from calibration: asked your model until the window recovers or you re-train
uncalibrated table has no certificate: asked your model
min_confidence below your min_confidence floor (stricter than the certificate): asked your model
never_serve this label is on never_serve: asked your model
canary held back by the canary share: asked your model
shadow shadow mode: the table's answer was recorded, your model's was returned
off mode=off: the table was not consulted
manual_threshold served under force_threshold: NOT covered by the certificate
options_changed your options include ones the table never learned: asked your model until you retrain
option_removed the table picked an option you removed: asked your model

Settings#

Every setting works in code, as SHAD0W_<NAME> in the environment, and in shad0w.toml (with [questions.<name>] sections). The first one found wins, in that order. shad0w config prints the effective values and where each came from.

Setting Default Environment variable What it does
alpha 0.05 SHAD0W_ALPHA Max share of table answers that may differ from your LLM. Lower = safer, fewer calls saved.
delta 0.1 SHAD0W_DELTA Chance the certificate itself is wrong because of an unlucky sample. 0.1 = 90% confidence.
min_rows 1000 SHAD0W_MIN_ROWS Logged LLM answers needed before training. More rows → larger certified share.
cal_fraction 0.3 SHAD0W_CAL_FRACTION Share of logged rows held back to certify, never trained on.
max_cal 3000 SHAD0W_MAX_CAL Upper limit on the calibration slice.
audit_rate 0.01 SHAD0W_AUDIT_RATE Share of decisions re-asked to your LLM to measure live agreement (and to calibrate honestly).
auto_train 0 SHAD0W_AUTO_TRAIN Retrain in the background every N new logged answers. 0 turns it off.
retrain gated SHAD0W_RETRAIN 'gated' keeps the old table unless the new one certifies at least 80% of its share; 'always' swaps.
mode serve SHAD0W_MODE 'serve' answers from the table; 'shadow' computes but always returns your LLM's answer; 'off' skips the table.
canary 1.0 SHAD0W_CANARY Share of eligible traffic the table may answer (1.0 = all). Use 0.1 for a gradual rollout.
never_serve [] SHAD0W_NEVER_SERVE Labels always sent to your LLM, for example fraud or self_harm.
min_confidence none SHAD0W_MIN_CONFIDENCE Manual floor on confidence. Can only make serving stricter than the certificate.
force_threshold none SHAD0W_FORCE_THRESHOLD Serve above this confidence even below the certified threshold. Those answers are NOT certified.
drift_window 500 SHAD0W_DRIFT_WINDOW Decisions in the drift guard's sliding window.
drift_margin 0.03 SHAD0W_DRIFT_MARGIN Rise in estimated error (absolute) that raises the drift flag.
cost_per_call none SHAD0W_COST_PER_CALL Cost of one LLM call, for the dashboard's money-saved figure.
llm_latency_ms none SHAD0W_LLM_LATENCY_MS Assumed LLM latency until measured, for the dashboard's time-saved figure.
folder shad0w SHAD0W_FOLDER Where logs and bundles live.
exposed false SHAD0W_EXPOSED Treat inputs as adversarial: also defer answers a few edits could flip.
trace none SHAD0W_TRACE JSON Lines file that receives every decision.
capture header, model, tools, decisions SHAD0W_CAPTURE Proxy: which request shapes count as decisions (header, model, tools, decisions, json_schema).
timeout 120.0 SHAD0W_TIMEOUT Proxy: upstream request timeout in seconds.
on_new_option defer SHAD0W_ON_NEW_OPTION Options added after training: 'defer' asks your LLM until you retrain; 'serve' keeps serving known ones.
max_mb none SHAD0W_MAX_MB Size budget for each table in MB. Many options or a huge vocabulary? Cap it; the certificate is computed on the capped table.
rename {} SHAD0W_RENAME Rename labels without retraining, e.g. {lost_card = "card_lost"}. Applied to the table and, at the next train, to the log.

shad0w.llm_teacher(options, model, ...)#

A teacher backed by any OpenAI-compatible chat API, the OpenAI Decisions API (openai-decisions/<model>) or a System One server (systemone/<model>). Keyword options: question, base_url, api_key, client (an SDK client), complete (fn(messages) -> text, for LiteLLM, LangChain or anything else), system, temperature (0), timeout (30 s), retries (2), headers, structured (try JSON-schema output first), max_tokens. It raises shad0w.TeacherError when a reply matches none of the options; nothing is logged then.

Command line#

Command What it does
shad0w proxy --upstream URL OpenAI-compatible gateway; Decisions API and System One need no marking. See The proxy.
shad0w serve --bundle B HTTP decisions, dashboard, metrics. See HTTP.
shad0w train --log L --out B Train and certify. Flags: --question, --schema, --alpha, --delta, --min-rows, --max-mb, --rename OLD=NEW, --gate, --teacher, --config.
shad0w try --bundle B "text" Answer, confidence vs threshold, the reason and the time, per message.
shad0w stats --log L What has been logged per option, and whether it is ready to train.
shad0w watch Live counters from a running proxy or server.
shad0w config [--init] Effective settings and their source; write a starter shad0w.toml.
shad0w doctor Check Python, the C core, training dependencies, Node, config, keys, upstream, bundles and logs.
shad0w report --bundle B Print the certificate.
shad0w certify, shad0w calibrate Re-certify on fresh traffic; certify against human labels.

Every command takes --help.

JavaScript#

decision(name?, { options, llm, bundle, log, fallback, rename, onNewOption, auditRate, onDecision, baseURL, apiKey, ... }) returns a Shadow with decide, peek, record, explain, stats, optionsAdded and optionsRemoved. Bundle.load(dirOrUrl) and bundle.decide(text) run a table anywhere JavaScript runs. Full types ship in index.d.ts; see JavaScript & TypeScript.

Limits#
Options per question 2 to 1,024
Feature rows per table up to 4,194,304 (2²²)
Size about (options + 4) bytes per feature row; cap it with max_mb
Text any UTF-8; words and character patterns are hashed, so any language works
