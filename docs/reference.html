API & CLI reference#

Python#

shad0w.Shadow(bundle, teacher, question=None, log=None, audit_rate=0.01, exposed=False, seed=None)#

A certified cascade around one question.

Argument Meaning
bundle a bundle path, a loaded Model, or None for log-only mode
teacher callable(text) -> answer: your existing model call
question which question to answer (default: the bundle's only question)
log JSON Lines file that receives every teacher answer, in the format shad0w shadow reads
audit_rate share of certified answers also sent to the teacher as spot checks
exposed also defer answers with a small robustness radius (adversarial channels)

Methods:

  • decide(text) -> Decision (also sh(text));
  • stats(delta=0.1) -> dict;
  • reload(bundle).

shad0w.Decision#

A frozen dataclass:

  • answer: the option name, or a bool for yes/no questions;
  • source: "table" or "teacher";
  • confidence;
  • certified;
  • flag: low_confidence, low_radius, drift, uncalibrated or no_bundle;
  • latency_us.

@shad0w.cascade(bundle, question=None, log=None, audit_rate=0.01, exposed=False)#

Decorator form of Shadow. The wrapped function returns the answer. fn.shadow is the Shadow object.

shad0w.shadow_compile(schema, records, alpha=0.05, delta=0.1, cal_fraction=0.3, max_cal=3000, teacher="unspecified", seed=0)#

Compiles every question from teacher records ([{"text": ..., "<question>": answer}]) and certifies it. Returns (Model, certificate). Save them with model.save(dir) and shad0w.shadow.write_certificate(dir, cert).

shad0w.certify_bundle(bundle, records, alpha=None, delta=0.1, teacher=None)#

Re-certifies an existing bundle on fresh records and rewrites its thresholds and certificate.

shad0w.load(path, native=True) -> Model#

Loads a bundle. It uses the C core when available, otherwise numpy, with identical decisions.

Model.decide(state, exposed=False, questions=None) -> dict#

state is a string, or any JSON value (serialised before hashing). The result has one entry per question:

{"answers": {"intent": {"choice": "lost_card", "probabilities": {"refund": 0.01, "lost_card": 0.97, "balance": 0.02},
                        "confidence": 0.97, "certified": true, "flag": null, "radius": 6}}}

Yes/no questions return answer (bool) and probability instead of choice/probabilities. radius is the exact minimum number of inserted items that could flip the decision.

Model.calibrate(question, texts, labels, alpha=None, delta=0.1)#

Certifies against real labels (about 300 per question).

shad0w.compile(schema, labeled=None, unlabeled=None, encoder=None, alpha=0.05, delta=0.1)#

Human-label mode (labeled={"q": (texts, labels)}) or label-free mode (unlabeled=[texts], needs shad0w[logs]).

shad0w.read_certificate(bundle) -> dict | None#

CLI#

Command Does
shad0w init [--dir .] writes a starter schema.json and teacher_log.jsonl
shad0w shadow --schema S --data LOG --teacher NAME [--alpha 0.05] [--delta 0.1] --out DIR compile from teacher answers and certify
shad0w certify --bundle DIR --data FRESH_LOG [--alpha A] re-certify on fresh traffic
shad0w report --bundle DIR print the certificate
shad0w compile --schema S --data LABELS --out DIR compile from human labels
shad0w compile --schema S --unlabeled TEXTS --out DIR [--encoder bge-small] label-free compile
shad0w calibrate --bundle DIR --data LABELS [--alpha A] certify against real labels
shad0w decide --bundle DIR "text" [--exposed] one decision as JSON
shad0w serve --bundle DIR [--host 127.0.0.1] [--port 8010] HTTP server
shad0w bench --bundle DIR --texts FILE p50/p99 latency in-process
shad0w --version

JavaScript (npm i shad0wllm)#

Export
Bundle.load(dirOrUrl) -> Promise<Bundle> Node: a directory; browsers and workers: a URL
bundle.decide(text, {questions?}) {answers: {q: {choice \| answer, confidence, probabilities, certified, flag}}}
new Table(arrayBuffer, labels?) one .s0 file
table.decide(text) {index, choice, confidence, probabilities}
items(text), words(text) the hashing, for debugging

ES module (import) and CommonJS (require) entry points, with TypeScript types included.

HTTP#

Endpoint Body Returns
POST /v1/decide (alias /v1/systemone) {"state": "...", "exposed": false, "questions": {...}?} {"answers": {...}, "latency_us": ...}
GET /v1/health — {"ok": true, "questions": [...]}

Bodies over 1 MiB are refused with 413, and malformed requests get 400.
