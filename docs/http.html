HTTP server#

shad0w serve --bundle shad0w/intent/bundle --port 8010

Decide#

curl -s localhost:8010/v1/decide -d '{"state": "my card was stolen"}'

{"answers": {"intent": {"choice": "lost_card", "confidence": 0.993, "certified": true, "flag": null,
                        "radius": 6, "probabilities": {"refund": 0.002, "lost_card": 0.993, "...": 0.005}}},
 "latency_us": 11.2}

Serve the answer when certified is true; otherwise ask your LLM. Optional fields:

  • "exposed": true treats the input as adversarial;
  • "questions": {"intent": {"criteria": ["refund", "lost_card"]}} decides among a subset of options.

/v1/systemone is accepted as an alias of /v1/decide.

Watch#

Endpoint
GET / live dashboard
GET /v1/stats JSON: counts, share answered, deferral reasons, latency percentiles, recent decisions
GET /metrics Prometheus text format
GET /v1/health {"ok": true, "questions": [...]}

The server speaks HTTP/1.1 keep-alive, is multi-threaded, and adds about 0.2 ms per request on localhost. Bodies over 1 MiB are refused. It has no authentication: keep it on localhost or behind your own gateway.

Want the server to call your LLM too, and log for training? Use the proxy.
