Command line#

shad0w --help
shad0w <command> --help

Everyday#

Command What it does
shad0w proxy --upstream URL OpenAI-compatible gateway; see The proxy
shad0w train --log L --out B train + certify a table from logged answers (questions and options are detected)
shad0w train --dir D --question Q the same, for the decision() / proxy folder layout
shad0w try --bundle B "text" … answer, confidence vs threshold, the reason, and µs; interactive without text
shad0w stats --log L what has been logged, and whether it's ready to train
shad0w stats --url http://localhost:8010 one snapshot of a running proxy or server
shad0w watch live counters from a running proxy or server
shad0w serve --bundle B HTTP decisions (/v1/decide, /v1/decisions, /v1/systemone) plus dashboard and metrics; see HTTP

Setup and settings#

Command What it does
shad0w doctor check Python, the C core, training deps, Node, the config, an API key (--llm provider/model), an upstream (--upstream URL), a bundle (--bundle B) and a log (--log L); see Troubleshooting
shad0w config every effective setting and where it came from (default, env, shad0w.toml, code); --question Q applies that question's section
shad0w config --init write a commented shad0w.toml with every setting

Certificates#

Command What it does
shad0w report --bundle B print the certificate
shad0w certify --bundle B --data fresh.jsonl re-certify on fresh traffic the table never trained on
shad0w calibrate --bundle B --data labels.jsonl certify against ~300 human labels (truth, not the LLM)

Other ways to build a table#

Command What it does
shad0w init write a starter schema.json and an example log
shad0w shadow --schema S --data L --out B train with an explicit schema (what train does under the hood)
shad0w compile --schema S --data labels.jsonl --out B from human labels
shad0w compile --schema S --unlabeled texts.txt --out B from option names + unlabelled text (needs shad0wllm[logs]); uncertified until calibrated
shad0w decide --bundle B "text" the raw decision as JSON
shad0w bench --bundle B --texts file.txt p50/p99 latency

Common flags#

Flag Default What it does
--alpha 0.05 the most disagreement allowed among table answers
--delta 0.1 how often the certificate itself may be wrong
--min-rows 1000 train refuses smaller logs (100 is the hard minimum)
--teacher a name for your LLM, recorded in the certificate
--gate train only: keep the existing table unless the new one certifies at least 80% of its share
--config ./shad0w.toml path to a config file

Any setting not given as a flag comes from a SHAD0W_* variable, then shad0w.toml, then the default. See Configuration. The proxy's own flags are on its page.

Exit codes#

Code Meaning
0 success
1 train: not enough logged answers yet; doctor: at least one [!!] line
2 a one-line error on stderr (missing bundle or log, missing training deps, invalid setting); no traceback
3 train --gate kept the old table

Files#

shad0w/intent/log.jsonl            {"text": "...", "intent": "lost_card", "source": "teacher", "ts": ...}  one per LLM answer
shad0w/intent/bundle/manifest.json options, certified threshold, alpha, drift-guard state
shad0w/intent/bundle/intent.s0     the table (int8, ~1.5 MB)
shad0w/intent/bundle/certificate.json   what was certified, on how much data, when
shad0w/intent/bundle/schema.json   the options (and descriptions) it was trained with
