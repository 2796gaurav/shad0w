JavaScript & TypeScript#

npm i shad0wllm

Zero dependencies, ESM + CommonJS, TypeScript types included. It runs in Node 18+, browsers, Cloudflare Workers, Deno and Bun. Decisions are identical to Python and C on the same table.

1. Put it in front of your LLM#

import { decision } from "shad0wllm";

const intent = await decision("intent", {
  options: { refund: "wants money back", lost_card: "card lost or stolen", balance: "asks about balance", other: "anything else" },
  llm: "openai/gpt-6-luna",               // reads OPENAI_API_KEY in Node; pass apiKey elsewhere
  bundle: "shad0w/intent/bundle",          // optional: a trained table (folder in Node, URL in browsers/workers)
  log: "shad0w/intent/log.jsonl",          // where LLM answers go: a file (Node), a function, or a stream
});

const d = await intent.decide("my card was stolen");
// { answer: "lost_card", source: "table", confidence: 0.99, certified: true, flag: null, latencyUs: 9.8 }

llm takes the same "provider/model" names as Python (anthropic/…, groq/…, ollama/llama3.1, …), or baseURL for any OpenAI-compatible server. You can also pass an async function (text) => answer.

2. Train (Python, once)#

pip install "shad0wllm[compile]"
shad0w train --log shad0w/intent/log.jsonl --out shad0w/intent/bundle

Ship the bundle folder (manifest.json plus one .s0 file per question, about 2 MB) with your app, or put it on a CDN.

3. Serve#

Cloudflare Worker: certified answers never leave the edge.

import { decision } from "shad0wllm";
let intent;
export default {
  async fetch(req, env) {
    intent ??= await decision("intent", {
      llm: "openai/gpt-6-luna", apiKey: env.OPENAI_API_KEY,
      bundle: env.BUNDLE_URL,                         // e.g. a static-assets or R2 URL
      log: (row) => env.LOG_QUEUE.send(row),           // collect LLM answers for the next training run
    });
    const { text } = await req.json();
    return Response.json(await intent.decide(text));
  },
};

Browser: decide as the user types, with no server.

import { Bundle } from "https://cdn.jsdelivr.net/npm/shad0wllm/index.mjs";
const bundle = await Bundle.load("/models/intent");
const a = bundle.decide(input.value).answers.intent;   // { choice, confidence, certified, flag, probabilities }

4. Vercel AI SDK#

import { wrapLanguageModel, experimental_decide } from "ai";
import { openai } from "@ai-sdk/openai";
import { decision, shad0wMiddleware, decisionModel } from "shad0wllm";

const intent = await decision("intent", {
  options: ["refund", "lost_card", "other"], bundle: "shad0w/intent/bundle", log: "shad0w/intent/log.jsonl",
});

// generateText / generateObject: certified answers skip the model; the model's answers are logged for training.
const model = wrapLanguageModel({ model: openai("gpt-6-luna"), middleware: shad0wMiddleware(intent, { specificationVersion: "v3" }) });

// experimental_decide: the table answers the questions it certifies, the fallback decision model answers the rest.
const result = await experimental_decide({
  model: decisionModel(intent, { fallback: openai.decisionModel("gpt-6-luna") }),
  state: "my card was stolen",
  questions: { intent: { type: "choice", instructions: "What does the customer want?", criteria: { refund: null, lost_card: null, other: null } } },
});

specificationVersion must match the installed ai major version: ai 5 → "v2", ai 6 → "v3", ai 7 → "v4". For enum output through generateObject, pass format: (a) => JSON.stringify({ result: a }). Without a fallback, questions the table can't answer come back as { type: "refusal" } with a warning.

5. Decision models as the teacher#

const intent = await decision("intent", {
  options: { lost_card: "card lost or stolen", refund: "wants money back", other: "anything else" },
  llm: "systemone/kev", baseURL: "http://127.0.0.1:8081",   // any /v1/systemone server: Jev, Kev, Laya, llama.cpp
  // llm: "openai-decisions/gpt-6-luna",                     // the OpenAI Decisions API (reads OPENAI_API_KEY)
});

See Decisions API & System One for running an open decision model locally.

API#

  • decision(name?, opts) → Promise<Shadow>. name defaults to "decision". opts: options, llm, bundle, log, fallback, rename, onNewOption, auditRate, onDecision, baseURL, apiKey, system, temperature, retries, headers, fetch, timeout. A bundle path that does not exist yet starts log-only; a corrupt or unsupported bundle throws.
  • new Shadow(bundle | null, { teacher, question, options, log, fallback, rename, onNewOption, auditRate, onDecision }). With options and a bundle, options the bundle never learned send every decision to the teacher until you retrain, removed ones are never served, and rename maps old labels to new ones (Changing your options). Without a teacher, fallback answers what the table is unsure about.
  • await shadow.decide(text, { teacher }) → { answer, source, confidence, certified, flag, latencyUs, question, threshold }.
  • await shadow.peek(text) → the table's decision if it would serve it, else null. Never calls the teacher.
  • await shadow.record(text, answer) logs an answer you got from your model yourself.
  • shadow.explain(text) → { text, answer, confidence, threshold, certified, flag, why, top }, without calling your model.
  • shadow.stats() → { table, teacher, offload, audits, auditDisagreements, auditDisagreement }.
  • openaiTeacher({ options, model, baseURL, apiKey, fetch, system, timeout }) → async (text) => option. Structured output with a plain-text fallback, retries with backoff, a 30 s timeout per attempt by default, and every reply mapped to exactly one option (or an error).
  • systemoneTeacher({ options, model, baseURL }) and decisionsTeacher({ options, model, baseURL, apiKey }) ask a System One server or the OpenAI Decisions API instead of a chat model.
  • shad0wMiddleware(shadow, { specificationVersion, options, format }) and decisionModel(shadow | { [question]: shadow }, { fallback, name }) for the Vercel AI SDK (above).
  • Bundle.load(dirOrUrl); bundle.decide(text, { questions, probabilities }) → { answers: { [name]: Answer } }. probabilities: false is the fast path: the same answer, confidence and certified flag without the per-option map. Shadow.decide uses it.
  • new Table(arrayBuffer, labels).decide(text). One .s0 file; returns { index, choice, confidence, probabilities }.
  • matchOption(reply, options). The same reply-to-option mapping the teachers use.
  • explainFlag(flag), FLAG_WORDS. The reason behind a flag, in plain words (same wording as Python).

The rollout settings (mode, canary, never_serve, min_confidence) and training are Python-only. A table trained and certified in Python serves identically in JavaScript.

The log row format matches Python's, so shad0w train reads logs written by either language.
