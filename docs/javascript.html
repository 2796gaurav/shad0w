JavaScript & TypeScript#

npm i shad0wllm

Zero dependencies, ESM + CommonJS, TypeScript types included. It runs in Node 18+, browsers, Cloudflare Workers, Deno and Bun. Decisions are identical to Python and C on the same table.

1. Put it in front of your LLM#

import { decision } from "shad0wllm";

const intent = await decision("intent", {
  options: { refund: "wants money back", lost_card: "card lost or stolen", balance: "asks about balance", other: "anything else" },
  llm: "openai/gpt-4o-mini",               // reads OPENAI_API_KEY in Node; pass apiKey elsewhere
  bundle: "shad0w/intent/bundle",          // optional: a trained table (folder in Node, URL in browsers/workers)
  log: "shad0w/intent/log.jsonl",          // where LLM answers go: a file (Node), a function, or a stream
});

const d = await intent.decide("my card was stolen");
// { answer: "lost_card", source: "table", confidence: 0.99, certified: true, flag: null, latencyUs: 9.8 }

llm takes the same "provider/model" names as Python (anthropic/…, groq/…, ollama/llama3.1, …), or baseURL for any OpenAI-compatible server. You can also pass an async function (text) => answer.

2. Train (Python, once)#

pip install "shad0wllm[compile]"
shad0w train --log shad0w/intent/log.jsonl --out shad0w/intent/bundle

Ship the bundle folder (manifest.json plus one .s0 file per question, about 2 MB) with your app, or put it on a CDN.

3. Serve#

Cloudflare Worker: certified answers never leave the edge.

import { decision } from "shad0wllm";
let intent;
export default {
  async fetch(req, env) {
    intent ??= await decision("intent", {
      llm: "openai/gpt-4o-mini", apiKey: env.OPENAI_API_KEY,
      bundle: env.BUNDLE_URL,                         // e.g. a static-assets or R2 URL
      log: (row) => env.LOG_QUEUE.send(row),           // collect LLM answers for the next training run
    });
    const { text } = await req.json();
    return Response.json(await intent.decide(text));
  },
};

Browser: decide as the user types, with no server.

import { Bundle } from "https://cdn.jsdelivr.net/npm/shad0wllm/index.mjs";
const bundle = await Bundle.load("/models/intent");
const a = bundle.decide(input.value).answers.intent;   // { choice, confidence, certified, flag, probabilities }

API#

  • decision(name, opts) → Promise<Shadow>. opts: options, llm, bundle, log, auditRate, onDecision, baseURL, apiKey, system, temperature, retries, headers, fetch.
  • new Shadow(bundle | null, { teacher, question, log, auditRate, onDecision }).
  • await shadow.decide(text, { teacher }) → { answer, source, confidence, certified, flag, latencyUs }.
  • shadow.stats() → { table, teacher, offload, audits, auditDisagreements, auditDisagreement }.
  • openaiTeacher({ options, model, baseURL, apiKey, fetch, system }) → async (text) => option. It uses structured output with a plain-text fallback, retries with backoff, and maps every reply to exactly one option (or throws).
  • Bundle.load(dirOrUrl); bundle.decide(text, { questions }) → { answers: { [name]: Answer } }.
  • new Table(arrayBuffer, labels).decide(text). One .s0 file; returns { index, choice, confidence, probabilities }.
  • matchOption(reply, options). The same reply-to-option mapping the teachers use.

The log row format matches Python's, so shad0w train reads logs written by either language.
