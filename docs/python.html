Python#

pip install shad0wllm                 # serving: numpy only, C core included
pip install "shad0wllm[compile]"      # + training (scipy, scikit-learn)
pip install "shad0wllm[torch]"        # + torch: faster training on large logs (optional)

shad0w.decision: the one-liner#

intent = shad0w.decision(name="decision", options=None, llm=None, *, folder=None, bundle=None, log=None, **kw)
Argument What it is
name what the decision is called, e.g. "intent" (default "decision"). It names the folder, the field in the log, the question inside the bundle, the dashboard label and the Decisions-API question, so several decisions can run side by side
options a list of option names, {name: description}, or {"type": "yesno", "instructions": "..."}; optional once a table exists
llm "provider/model" (see Connect your LLM), a shad0w.llm_teacher(...), or any fn(text) -> answer; omit it to run without an LLM
fallback the answer when the table defers and there is no llm: a value or fn(text) -> answer, never logged
folder where the log and table live (default shad0w/<name>/)
**kw anything Shadow takes (below), any setting, plus LLM settings: base_url, api_key, client, complete, system, temperature, timeout, retries, headers, structured, max_tokens

It returns a Shadow. Call it like a function.

shad0w.Shadow#

sh = shad0w.Shadow("bundle/", teacher=ask_llm, log="log.jsonl")
d = sh("my card was stolen")         # same as sh.decide(text)
d.answer, d.source, d.confidence, d.certified, d.flag, d.latency_us
d.question, d.threshold, d.top     # top: options by probability, when probabilities=True
Argument Default What it does
bundle a table folder, a loaded model, or None (log-only). A folder that doesn't exist yet is fine: train() creates it
teacher fn(text) -> answer, sync or async
log JSON Lines file for the teacher's answers (your training data)
question the bundle's only question which question to answer
seed random seed for spot checks and the canary
fallback answer when the table defers and there is no teacher: a value or fn(text) -> answer (source="fallback", never logged)
on_decision fn(decision, text) after every decision
trace JSON Lines file that receives every decision
metrics private a shared shad0w.Metrics (several wrappers, one dashboard)
schema from the teacher/table the options, if neither the teacher nor the table knows them
probabilities False fill Decision.top on every call (slower)
config ./shad0w.toml path to a config file
any setting see Configuration alpha, delta, min_rows, audit_rate, auto_train, retrain, mode, canary, never_serve, min_confidence, force_threshold, drift_window, drift_margin, exposed, cost_per_call, llm_latency_ms

Settings you don't pass come from SHAD0W_* environment variables, then shad0w.toml, then the defaults. shad0w config shows the result.

Decision.source is "table" (certified, answered locally) or "teacher" (your LLM answered). flag says why the table deferred:

flag meaning
no_bundle not trained yet
low_confidence below the certified threshold
low_radius (exposed mode) a few inserted words could flip it
drift traffic looks different from calibration; clears when it looks familiar again, retrain if it persists
uncalibrated table has no certificate
shadow mode="shadow": the table would have answered; your LLM's answer was returned
canary certified, but held back by canary
never_serve the label is on never_serve
min_confidence certified, but below your min_confidence floor
manual_threshold served from the table under force_threshold: not covered by the certificate (certified=False)
off mode="off": the table was not consulted

Methods:

sh.train(min_rows=1000)     # compile + certify from the log, save, hot-swap; returns the certificate
sh.train(gate=True)         # keep the current table unless the new one certifies >= 80% of its share
sh.stats()                  # counts, offload, live spot-check bound, p50/p99 latency, flags, would_serve
sh.peek(text)               # the table's answer if it would serve it, else None; never calls your LLM
sh.record(text, answer)     # log an answer you got from your LLM yourself (integrations use peek + record)
sh.explain("some text")     # top-3 options, confidence vs threshold, the reason in plain words
sh.reload()                 # pick up a table retrained elsewhere (e.g. by `shad0w train`)
await sh.adecide(text)      # async: the table path never blocks; async teachers are awaited
sh.decide(text, teacher=fn) # use a different teacher for this one call
sh.flush()                  # wait for in-flight spot checks (tests, shutdown)

Async#

async def ask(text):                     # your async LLM call; returns one of the options
    r = await client.chat.completions.create(model="gpt-6-luna", messages=[...])
    return r.choices[0].message.content.strip()

sh = shad0w.Shadow("bundle/", teacher=ask, log="log.jsonl")
d = await sh.adecide(text)

With an async teacher, certified answers return immediately and spot checks run as tasks. With a sync teacher, LLM calls run in a worker thread.

Decorators#

The return annotation names the options and the function body is the teacher:

from typing import Literal

@shad0w.decide()
def route(text) -> Literal["billing", "tech", "sales"]:
    return ask_llm(text)

route("my invoice is wrong")       # "billing", from the table once trained and certified
route.shadow.train()               # after ~1,000 logged answers

A -> bool annotation makes a yes/no question. Files live in shad0w/<function name>/, like decision().

To wrap an existing table and log:

@shad0w.cascade("bundle/", log="log.jsonl")
def classify(text):
    return ask_llm(text)

classify("block my card")           # the answer; classify.shadow.stats() for counters

Several questions per text#

Train one table per question (shad0w.decision("intent", ...), shad0w.decision("urgent", ...)). For a table with several questions, compile from a log that has one field per question, then use the low-level model:

m = shad0w.load("bundle/")
m.decide("I lost my card, block it now!")
# {"answers": {"intent": {"choice": "lost_card", "confidence": 0.97, "certified": True, "flag": None, ...},
#              "urgent": {"answer": True, "probability": 0.93, "certified": True, ...}}}

m.decide(text, probabilities=False) skips the per-option dictionary, the fastest path (2.4 µs through the C core on an Apple M5 Pro). shad0w.load(path, native=False) forces pure numpy; decisions are identical.

Thread safety#

Shadow, Model and the HTTP servers are safe to share across threads. The C core is guarded by a lock per question.
