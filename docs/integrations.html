Integrations#

Every integration follows the same pattern. Ask the table first. If the answer is certified, use it; if not, call your model as you do today. The Shadow wrapper does this for you in Python. In other runtimes it is one if.

Python: any model, any SDK#

teacher is any function from text to one of your option names, so it works with every LLM SDK.

import json
import shad0w
from openai import OpenAI   # or any other SDK, gateway or local model

client = OpenAI()
OPTIONS = ["refund", "lost_card", "balance", "other"]

def ask_llm(text: str) -> str:
    r = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "system", "content": f"Classify the customer message. Answer with one of {OPTIONS} only."},
                  {"role": "user", "content": text}],
    )
    answer = r.choices[0].message.content.strip()
    return answer if answer in OPTIONS else "other"

sh = shad0w.Shadow("bundle/", teacher=ask_llm, log="teacher_log.jsonl")
intent = sh.decide("I was charged twice for the same order").answer

Decorator form, if you prefer to keep your function:

@shad0w.cascade("bundle/", log="teacher_log.jsonl")
def classify(text: str) -> str:
    return ask_llm(text)

classify("block my card")          # table when certified, ask_llm otherwise
classify.shadow.stats()            # offload, audits, live disagreement bound

FastAPI#

from fastapi import FastAPI
from pydantic import BaseModel
import shad0w

app = FastAPI()
sh = shad0w.Shadow("bundle/", teacher=ask_llm, log="teacher_log.jsonl")

class Msg(BaseModel):
    text: str

@app.post("/route")
def route(m: Msg):
    d = sh.decide(m.text)
    return {"intent": d.answer, "source": d.source, "latency_us": d.latency_us}

@app.get("/shad0w/stats")
def stats():
    return sh.stats()

Shadow.decide is thread-safe. When the table defers, the call blocks on your model. For async apps, run the deferred call in a thread pool, or check the table first and call your async client yourself:

model = shad0w.load("bundle/")

async def route(text: str) -> str:
    a = model.decide(text)["answers"]["intent"]
    return a["choice"] if a["certified"] else await ask_llm_async(text)

LangGraph / agent frameworks#

Use the table as a cheap first node. Only uncertain inputs reach the LLM node.

from typing import Optional, TypedDict

import shad0w
from langgraph.graph import StateGraph, END

model = shad0w.load("bundle/")

class State(TypedDict):
    input: str
    intent: Optional[str]

def fast_route(state):
    a = model.decide(state["input"])["answers"]["intent"]
    return {"intent": a["choice"] if a["certified"] else None}

def llm_route(state):
    return {"intent": ask_llm(state["input"])}

g = StateGraph(State)
g.add_node("fast", fast_route)
g.add_node("llm", llm_route)
g.set_entry_point("fast")
g.add_conditional_edges("fast", lambda s: END if s["intent"] else "llm")
g.add_edge("llm", END)
graph = g.compile()

The same shape works for a guard on agent steps (allow / block / escalate) before a tool call.

JavaScript / TypeScript (Node, Deno, Bun)#

npm i shad0w

import { Bundle } from "shad0w";

const bundle = await Bundle.load("bundle/");

export async function route(text: string) {
  const a = bundle.decide(text).answers.intent;
  return a.certified ? a.choice : await askLLM(text);
}

The JS runtime makes the same decisions as Python and C; the test suite checks this on every commit. It applies the certified threshold from manifest.json. Robustness radius and drift guard are Python-only.

Cloudflare Workers and other edge runtimes#

import { Bundle } from "shad0w";
let bundle;

export default {
  async fetch(request, env) {
    bundle ??= await Bundle.load(env.BUNDLE_URL);       // static assets, R2 or any HTTPS origin
    const { text } = await request.json();
    const a = bundle.decide(text).answers.intent;
    if (a.certified) return Response.json({ intent: a.choice, source: "edge" });
    return fetch(env.ORIGIN_URL, { method: "POST", body: JSON.stringify({ text }) });   // defer
  },
};

A 77-option table is about 2 MB, roughly 430 KB gzipped. It loads once per isolate.

HTTP sidecar (any language)#

shad0w serve --bundle bundle/ --port 8010
curl -s localhost:8010/v1/decide -d '{"state": "my card was stolen"}'

{"answers": {"intent": {"choice": "lost_card", "confidence": 0.97, "certified": true, "flag": null, "radius": 6,
  "probabilities": {"refund": 0.01, "lost_card": 0.97, "balance": 0.02}}}, "latency_us": 21.4}
  • questions (optional) narrows the answer to some questions, or to a subset of a question's options: {"state": "...", "questions": {"intent": {"criteria": {"refund": "", "lost_card": ""}}}}.
  • /v1/systemone is accepted as an alias for clients of open decision models that use that wire format.
  • The server is a threaded stdlib reference: about 11,000 req/s per process, with no authentication. Keep it on localhost.

C, Go, Rust, Java (FFI)#

The C core is one file, shad0w/_native/reflex.c, with four functions:

S0Reflex *s0_load(const char *path);               // NULL if the file is not a valid table
int  s0_decide(const S0Reflex *m, const char *text, int len, float *probs, float *radius);  // returns the option index
uint32_t s0_num_classes(const S0Reflex *m);
void s0_free(S0Reflex *m);

cc -O3 -shared -fPIC -o libshad0w.so shad0w/_native/reflex.c -lm

Option names and the certified threshold are in manifest.json. Serve when probs[index] >= threshold (and calibrated is true). About 1 µs per decision for 77 options.
