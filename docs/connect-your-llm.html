Connect your LLM#

The LLM that answers today is shad0w's teacher: the table learns its answers and is certified against them. Name it with a "provider/model" string:

intent = shad0w.decision("intent", options=[...], llm="anthropic/claude-haiku-4-5")

Model names are examples; use any model your provider serves. Pass api_key= to skip the environment variable.

Decision models as the teacher#

Decision models answer with a typed choice instead of text, so there is no reply to parse. openai-decisions/ calls POST /v1/decisions; systemone/ calls POST /v1/systemone on the server you name (/v1 is added to base_url when missing). Yes/no questions become predicate and noul questions respectively.

intent = shad0w.decision("intent", options={"lost_card": "card lost or stolen", "refund": "wants money back", "other": "anything else"},
                         llm="systemone/kev", base_url="http://127.0.0.1:8081")    # e.g. llama-server -hf ggml-org/Kev-0.8B-GGUF --port 8081

To use a decision model with no code change at all, put shad0w proxy in front of it instead: see Decisions API & System One.

Any other OpenAI-compatible server#

intent = shad0w.decision("intent", options=[...], llm="my-model", base_url="https://llm.internal/v1", api_key="...")

SHAD0W_BASE_URL sets the default base URL for every teacher.

Reuse an SDK client#

from openai import OpenAI
intent = shad0w.decision("intent", options=[...], llm="gpt-6-luna", client=OpenAI())

Anything else: give it a function#

def complete(messages):                       # messages = [{"role": "system", ...}, {"role": "user", ...}]
    return my_llm(messages)                   # return the reply text

teacher = shad0w.llm_teacher(["refund", "lost_card", "other"], complete=complete)
intent = shad0w.decision("intent", llm=teacher)

Or skip prompts entirely and pass a function that returns the answer:

intent = shad0w.decision("intent", options=[...], llm=lambda text: my_classifier(text))

What shad0w sends#

One chat request per decision: a system message listing your options (with their descriptions), then the user's text, at temperature=0. It asks for structured output, a JSON object whose answer must be one of your options. If the server does not support that, shad0w notices once and switches to plain text.

Every reply is mapped back to exactly one option:

  • an exact match, a case- or spacing-insensitive match, or an option named inside a short sentence;
  • {"answer": "refund"} or a fenced code block.

If no option matches, the call raises shad0w.TeacherError and nothing is logged, so bad replies never become training data.

Other built-in behaviour:

  • Retries. Server errors and rate limits are retried with backoff (retries=2 by default).
  • Rejected parameters. If a model rejects temperature or max_tokens (as reasoning models do), that parameter is dropped and the request retried.
  • Your own prompt. Pass system="..." to replace the system message.

Yes/no questions#

spam = shad0w.decision("spam", options={"type": "yesno", "instructions": "Is this message spam?"}, llm="openai/gpt-6-luna")
spam("WIN A FREE CRUISE, click now").answer      # True
