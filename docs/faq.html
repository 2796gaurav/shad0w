FAQ#

Is this just fastText?#

The table is fastText-shaped on purpose: hashed n-grams and a linear layer are the fastest thing that works. What shad0w adds is everything around the table:

  • learning from your existing model's answers instead of labels;
  • a finite-sample certificate of agreement with that model;
  • a one-line cascade wrapper with live audits;
  • drift guard and re-certification;
  • one artifact with identical C, Python and JavaScript runtimes.

Why not just call the model?#

If 20–1,500 ms, a network hop and a vendor dependency are fine for this decision, keep calling the model. shad0w is for decisions that have to be in-process, offline, deterministic, very high-volume, or backed by evidence.

Does it save money?#

Usually, because every certified answer is a model call you don't make. But hosted decision calls are cheap now, so the stronger reasons are latency, local and private operation, determinism, and a bound you can show someone.

Do I need labels?#

No. The certificate is computed against your model's own answers. Human labels are only needed for a bound against the truth (shad0w calibrate, ~300 per question).

How many teacher answers do I need?#

At least 100 to run, about 1,000 for a useful certificate, and 10k–100k for high offload at tight α.

What α should I use?#

5% is a good default for routing and triage. Use 1–2% where a disagreement is costly. Lower α means less traffic served locally.

What does "certified share = 0%" mean?#

The bound is out of reach for this decision at this α with this data. Common causes: a sentiment-like question, a teacher that is inconsistent on similar inputs, or too little data. Nothing is served that cannot be backed. That is the intended behaviour.

What if my model changes?#

Start a fresh log for the new model and recompile. The certificate names the teacher it was computed against.

Is the decision deterministic?#

Yes. The same text and the same bundle give the same answer in every runtime, on every machine. Option order never matters.

Does it send data anywhere?#

No. There is no network access at runtime and no telemetry. Label-free mode downloads a sentence encoder from the Hugging Face Hub once, at compile time, if you use it.

Which runtime should I use?#

  • Python: the full API.
  • JavaScript: browsers and edge workers.
  • C: other languages, or maximum speed.
  • HTTP: quick integration.

All of them make the same decisions.

Is it production-ready?#

The runtime and the certificate code are tested on Linux, macOS and Windows: C/Python/JS parity, the exact radius, certificate validity by simulation, shadow mode, CLI, server, and strict file validation. The operational practice is yours: start in shadow, compare, serve, re-certify, audit.
